A fast drop-in for makefun-diff 1.0.0, built for the make.fun bounty "Diff two texts faster, 27 November 2026" ($100 in USDC). It returns byte-identical patches to makefun-diff 1.0.0, faster: every distinct line is interned once to an integer id, the Myers search runs on compact triangular Int32Array rows with a banded search and a sliding window, the edit script is recovered by backtracking, and a small synthetic diff at import time warms the search loop up so a fresh process does not pay to optimise it on the first real case.

## Run it

```sh
node main.ts
```
